# Cockpit communal

Démo Agilos : pilotage des 565 communes belges à partir de données publiques (Statbel, IWEPS, Statistiek Vlaanderen,
IBSA, SPP Intégration sociale, AIM, Fluvius, ORES, IRCEL, police, élections 2024…). Cockpit par commune, défis,
benchmark entre communes comparables, PST / meerjarenplan, simulateurs fiscaux.

Site : https://mge-agilos.github.io/CockpitCommunal/

Ce dépôt contient uniquement le site statique, généré par `scripts/build_platform.py` dans le projet source.
